# Automation Case Studies

Write-ups of automation work from my time as Supervisor, Onsite IT & Automation Systems. Each one covers the problem, what I did, and the result. Figures marked as estimates are estimates; everything else is a measured count.

These describe real employer work, so they contain no production code or environment details. For hands-on builds with code, see my lab repositories, such as [n8n Onboarding Automation](https://github.com/derrick-a-automation/n8n-onboarding-automation).

---

## Delivered

### 1. Zero-Touch Identity: Password and Account Expiration Automation
Scheduled PowerShell automation against on-premises Active Directory (synced to Entra ID) for ~2,600 users. Sent 9,000+ proactive notifications to users and managers, covering an estimated 380 hours a year of manual work and avoiding an estimated up to 1,800 service desk tickets.
**[Open case study](zero-touch-identity/)** · [PDF](zero-touch-identity/docs/)

### 2. Power Query Ingestion Framework
Replaced an inherited, manual quarterly chargeback data-prep process with a reusable Power Query ETL framework pulling from credentialed SharePoint Online sources, with output validated against the vendor's year-end report. Cut recurring prep time by an estimated 70–90% with no loss in accuracy.
**[Open case study (PDF)](power-query-ingestion-framework/)**

## Proposed

### 3. AI-Enhanced IT Intake Modernization (roadmap)
A phased roadmap, presented to leadership, for modernizing ServiceNow intake: AI-guided request selection, automatic device capture, Virtual Agent dialogs, Predictive Intelligence routing and adaptive forms, with a modeled ROI based on a 10,000-ticket annual baseline.
**[Open roadmap (PDF)](it-intake-modernization-framework/docs/)**
